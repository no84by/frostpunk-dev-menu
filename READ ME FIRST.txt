FROSTPUNK DEV MENU (F10)
========================

Press F10 in a running city to open Frostpunk's own built-in developer panel.

We did not make this panel. It was built by 11 bit studios and is part of every copy of
Frostpunk 1; the game just has no key that opens it. This mod only adds F10.

INSTALL (quit Frostpunk first)
  Windows:   double-click  Install Dev Menu (Windows).bat
             ("Windows protected your PC"?  More info -> Run anyway)
  macOS:     double-click  Install Dev Menu (Mac).command
             (first time: right-click -> Open; macOS 15+: System Settings ->
              Privacy & Security -> Open Anyway)
  Linux / Steam Deck (Desktop Mode):  bash install-dev-menu-linux.sh

Then load a city and press F10. Press F10 again to hide the panel.
To uninstall, run the same file again and choose Uninstall.

YOU INSTALL IT ONCE
The change is saved in the game files, so F10 keeps working every time you start Frostpunk
from Steam as usual; there is nothing to run before playing. Run the installer again only
after a Frostpunk update or a Steam "Verify integrity of game files" (if F10 suddenly stops
working, that is why).

THE THREE FILES ABOVE ARE ONLY LAUNCHERS
They do not change the game. All the work is done by dev_menu.py, a Python script. The
launchers only find Python on your computer and start dev_menu.py, so you can double-click
instead of typing commands. If Python is missing they offer to start the official Python
installer (winget / python.org on Windows, python.org on macOS, your package manager on Linux);
you approve it yourself with the usual system prompt, then the launcher carries on.

RUN IT WITHOUT THE LAUNCHERS
With Python 3.6+ installed, open a terminal in this folder and run:
  python3 dev_menu.py               (Windows: py -3 dev_menu.py)
  python3 dev_menu.py install | uninstall | status
  python3 dev_menu.py install --game-dir "path to your Frostpunk folder"

BE CAREFUL
Some panel buttons change your city permanently. Use a copy of your save.
A game update or Steam "Verify integrity" removes the mod; just install it again.
